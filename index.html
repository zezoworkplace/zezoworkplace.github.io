AUREUS Secure Backup

A private tool for creating encrypted, off-site backup copies of files under the account holder's control.

AUREUS Secure Backup is intended for authorized, single-account use. It uses Google Drive to store backup copies created by its administrator. It is not a public file-storage product, and it does not provide public registration or access to backup contents.

How it works

  1. The administrator selects approved local backup files.
  2. When enabled, files and filenames will be encrypted on the administrator’s system before upload using Rclone Crypt.
  3. After setup and authorization, encrypted copies will be stored within the authorized Google Drive account and can be retrieved for recovery by the administrator.

Google Drive permissions

The utility requests the Google Drive drive.file permission. This allows access to files that the application creates or that the account holder explicitly authorizes for the application. It does not request unrestricted access to unrelated existing Google Drive files. Authorized files may be created, listed, retrieved, updated or deleted as required for backup management and recovery.

Security and privacy

The planned backup workflow encrypts backup contents before transmission to Google Drive. Automated cloud backups are not yet active. Encryption credentials are retained under the administrator's control. Google Drive may still process account and storage metadata, such as file sizes and timestamps. Only the authorized account holder controls the backup workflow.
